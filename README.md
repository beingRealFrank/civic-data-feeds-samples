# civic-data-feeds-samples

Weekly sample pages from four public-records data feeds on Apify, published at https://beingrealfrank.github.io/civic-data-feeds-samples/ :

- [EU & UK public tenders](https://apify.com/civic_data_feeds/public-tenders-monitor)
- [US federal grants](https://apify.com/civic_data_feeds/us-grants-monitor)
- [US power plant pipeline](https://apify.com/civic_data_feeds/us-power-plant-pipeline)
- [CanadaBuys tenders](https://apify.com/civic_data_feeds/canadabuys-tenders-monitor)

Each page is a small slice with a CSV download and a link to the full, filterable feed. Data comes from official public sources; see each Actor page for sources and licences.

Maintained by Frank Gilroy.
